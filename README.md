# ISR

ISR（Image Sequence Renamer）是一个完全在本机运行的图片批量重命名工具。同一套界面可以作为浏览器网页使用，也可以通过 Electron 作为 Windows 桌面软件运行。

## 功能

- 扫描并显示指定文件夹第一层中的图片缩略图。
- 按文件创建时间、修改时间或大小正序/倒序排列。
- 日期和大小排序直接使用批量编辑：按住左键划过图片形成选中组，沿原路径折返会连同拐点逐张取消；短按已选图片会取消，移动超过小阈值或按住约 180 毫秒才开始拖动。
- 拖动时显示图片数量，固定起始布局及左右对称的吸附滞回可防止落点抖动，间隙标记会实时预览新顺序。
- 自定义顺序分为两个阶段：首先从空队列开始，用户按希望的命名顺序点击或划过全部图片；松开左键后自动进入批量调整阶段，可继续划选和拖动图片修正局部顺序。
- 自定义文件名前缀、起始编号和补零位数，例如 `旅行-001.jpg`。
- 重命名前实时预览最终文件名。
- 采用两阶段重命名，能够安全处理新旧文件名互相占用的情况。
- 执行前检查目标重名与文件是否被外部修改；失败时尽力恢复原文件名。
- 支持 JPG、JPEG、PNG、GIF、WebP、BMP、TIFF 和 AVIF。

> 图片不会上传到网络。后端只监听本机地址 `127.0.0.1`。建议先对重要图片保留备份。

## 双模式说明

- **网页 PWA 模式**：使用最新版 Chrome 或 Edge 打开网站，点击“选择图片文件夹”并授予读写权限。扫描、预览和重命名都在浏览器本地完成，不上传图片；生产构建可以部署到 GitHub Pages 等静态网站服务，并支持安装为 PWA。
- **桌面模式**：通过 Electron 和本地 API 使用系统文件夹对话框及原生两阶段重命名，对浏览器兼容性没有要求。

网页模式受浏览器文件系统接口限制，文件名变更通过安全的临时副本流程完成，可能更新文件的系统时间；重要图片建议保留备份。桌面模式使用操作系统原生重命名，能更好地保留文件属性。

## 环境要求

- Node.js 20 或更高版本
- npm 10 或更高版本

## 安装

```bash
npm install
```

## 浏览器网页版

开发模式（自动刷新）：

```bash
npm run dev
```

打开 `http://localhost:5173`，点击“选择图片文件夹”并授权即可。网页不需要知道或上传文件夹的绝对路径。

生产模式：

```bash
npm run build
npm start
```

打开 `http://127.0.0.1:8787`。

## Windows 桌面版

### 普通用户安装

下载并运行 `ISR.exe` 安装程序。安装完成后，从桌面快捷方式或开始菜单启动 ISR；普通用户不需要安装 Node.js，也不需要执行 npm 命令。

安装位置可以选择普通文件夹，也可以只选择磁盘根目录。选择 `D:\` 时，安装器会在开始安装时自动创建并使用 `D:\ISR`，不会把程序文件直接放入磁盘根目录。

### 开发者从源码运行

```bash
npm run desktop
```

该命令用于开发和调试，直接从项目源码构建并启动桌面版，不是普通用户安装后的启动方式。

### 开发者生成安装程序

```bash
npm run package:win
```

生成的 Windows 安装程序位于 `release/ISR.exe`。

## 测试

```bash
npm test
```

测试覆盖文件名互换、补零编号、扩展名保留和非法前缀拦截。

## 使用步骤

1. 输入路径或在桌面版中选择图片文件夹，然后点击“扫描图片”。
2. 输入前缀并选择日期、大小或“自定义顺序”。
3. 自定义顺序下，按希望的命名顺序点击或划过全部图片；全部完成后可使用批量拖动继续调整。
4. 在右侧命名队列检查新文件名，也可用上下按钮微调顺序。
5. 点击“重命名”，确认后一次性修改原文件名。

## 项目结构

```text
src/             React 网页界面
server/          Express 本地 API 与重命名引擎
electron/        Electron 桌面入口与安全预加载脚本
```
