# FSR

FSR（File Sequence Renamer，文件序列重命名器）是一款完全在本机运行的批量文件重命名工具，同一套界面可作为浏览器 PWA 或 Windows 桌面软件使用。**该项目完全由AI编写，用来提高日常中重复操作的效率**

## 功能

- 扫描指定文件夹第一层中的普通文件，不修改子文件夹。
- 可筛选全部文件、图片、视频、音频、文档、压缩包或其他文件；切换类型后只显示并处理当前类型。
- 图片显示缩略图，视频显示视频画面，其他类型显示清晰的类型卡片。
- 按创建时间、修改时间或文件大小正序/倒序排列。
- 支持自定义顺序、路径划选、批量选择和成组拖动排序。
- 自定义文件名前缀、起始编号和补零位数，并保留每个文件原有扩展名。
- 重命名前实时预览最终文件名，并检查目标重名和扫描后的文件变化。

## 双模式说明

- **网页 PWA 模式**：使用最新版 Chrome 或 Edge 选择文件夹并授予读写权限，扫描、预览和重命名都在浏览器本地完成。
- **桌面模式**：通过系统文件夹对话框选择目录，使用操作系统原生重命名，更适合保留文件属性和处理大量文件。

网页版为了安全地完成改名会使用临时副本，可能更新文件的系统时间；桌面版使用原生重命名。

## 环境要求

- Node.js 20 或更高版本
- npm 10 或更高版本

## 安装依赖

```powershell
npm install
```

## 浏览器网页版

在项目目录下用 `PowerShell` 启动：

```powershell
npm run dev
```

打开 `http://localhost:5173`，选择文件夹并授权即可。


## Windows 桌面版

下载并运行 `FSR.exe`。安装完成后，从桌面快捷方式或开始菜单启动 FSR；不需要安装 Node.js。

## 使用步骤

1. 选择目标文件夹。
2. 选择“全部文件”或一种具体文件类型；界面只显示当前筛选结果。
3. 输入前缀并选择日期、大小或“自定义顺序”。
4. 检查预览，可通过划选和批量拖动继续调整顺序。
5. 点击“重命名”，确认后一次性修改当前筛选结果中的文件名。

## 项目结构

```text
src/             React 网页界面与浏览器文件处理
server/          Express 本地 API 与原生重命名引擎
electron/        Electron 桌面入口与安全预加载脚本
```
